# Election Results 

Use pre-election data to prepare for watching election results.

## 2026 

- We want to look at the following data for each U.S. House district/election:
  - The incumbent
  - Harris/Trump 2024, Biden/Trump 2020, and PVI for each district
  - The current candidates for the district 
- There is a collection of polling data from the NY Times in [`2026/polls`](2026/polls).
- There are candidate listings at [Ballotpedia](https://ballotpedia.org/List_of_congressional_candidates_in_the_2026_elections)
